# Generic Rules

Portable engineering rules. Copy this folder into any codebase.

Nothing here is project-specific. Per-repo `AGENTS.md` overrides anything here on conflict.

- `clean-code.md` — coding standards and anti-patterns.
- `code-review.md` — bug and security review checklist.
- `documentation.md` — README, API docs, comments, and handoff templates.
- `writing.md` — prose and doc-writing rules.
